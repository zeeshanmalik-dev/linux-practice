# File System Notes

I practised Linux file system commands in my linux-practice folder.

1. pwd
Shows the current folder I am in.

2. ls -lah
Lists files and folders in detail, including hidden files and permissions.

3. cd
Moves into another folder, for example: cd projects

4. touch
Creates a new empty file, for example: touch notes.txt

5. mkdir
Creates a new folder, for example: mkdir archive

6. mv
Moves or renames a file, for example: mv todo.txt archive/

What I learned:
I learned how to move around the terminal, list files, create files and folders, and organise files into directories.
